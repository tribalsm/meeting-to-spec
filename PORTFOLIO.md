# Meeting to Spec - описание для портфолио

## В одном предложении

Meeting to Spec - сервис, который превращает аудио- или видеозапись встречи в проверяемый черновик технического задания с транскрипцией, требованиями и связанными фрагментами разговора.

## Краткое описание

Проект решает задачу подготовки первого черновика ТЗ после встречи, когда важные договорённости остаются только в записи разговора. Backend принимает медиафайл, получает транскрипцию с таймкодами через Whisper Large V3 Turbo и передаёт её в два специализированных LLM-прохода. GPT-OSS 120B формирует основную структуру ТЗ, а GPT-OSS 20B дополнительно ищет ограничения, условия, открытые вопросы, договорённости и противоречия. Интерфейс позволяет проверить источники требований, отредактировать результат и экспортировать его в Markdown.

## Для резюме

- Разработал FastAPI backend для обработки аудио и видео, валидации файлов и выдачи единого JSON-контракта для frontend.
- Интегрировал двухэтапный AI pipeline на Groq: Whisper Large V3 Turbo, GPT-OSS 120B и специализированный GPT-OSS 20B с merge без дублей и fallback при ошибке второго прохода.
- Выполнил интеграцию frontend и backend, deployment на VPS, debugging и интеграционное тестирование перед финальной демонстрацией.

## Что рассказать на техническом собеседовании

Начните с задачи: запись встречи сама по себе неудобна для работы с требованиями, поэтому сервис формирует черновик ТЗ с привязкой к источнику. Расскажите, почему pipeline разделён на распознавание речи и два LLM-прохода: большая модель формирует основной документ, а узкий второй запрос улучшает полноту дополнительных категорий. Отдельно подчеркните отказоустойчивость: ответ второго прохода объединяется без дублей, но его ошибка не отменяет основной анализ. Завершите разговором о практических ограничениях MVP: лимите размера файла, rate limit внешнего API, необходимости проверки результата человеком и возможной очереди задач для долгих записей.

## Мой технический вклад

- backend и HTTP API;
- интеграция компонентов и frontend/backend;
- AI-интеграция на стороне backend;
- deployment на VPS;
- debugging и интеграционное тестирование перед финалом.
