# Frontend Meeting to Spec

Интерфейс на React, TypeScript и Vite для загрузки записи и проверки результата анализа.

## Возможности

- загрузка MP3, MP4, WAV, M4A и WebM до 25 МиБ;
- оформленный плеер с громкостью, скоростью и перемоткой;
- переходы между этапами загрузки, анализа и результата;
- автоматический переход к готовому результату;
- поиск по транскрипции с переходом между совпадениями;
- подсветка фрагментов, подтверждающих требования и сценарии;
- добавление, изменение и удаление требований;
- экспорт текущего результата в читаемый Markdown.

## Запуск

Сначала запустите backend на `127.0.0.1:8000`, затем:

```powershell
npm ci
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Vite перенаправляет `/api` и `/health` на локальный backend. Локальный `.env` для frontend не нужен.

## Проверки

```powershell
npm test -- --run
npm run lint
npm run build
```

Тесты подменяют `fetch` и не обращаются к платным API.

## Публикация

Задайте `VITE_API_URL` перед сборкой или настройте reverse proxy для `/api`. Значения с префиксом `VITE_` доступны браузеру, поэтому ключи Groq и YandexGPT туда добавлять нельзя.
