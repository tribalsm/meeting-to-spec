# Meeting to Spec - Хакатон 2026

Сервис превращает запись встречи в черновик технического задания. Пользователь загружает аудио или видео, получает транскрипцию с таймкодами, требования, роли, сценарии, ограничения, вопросы и договоренности. Результат можно проверить, отредактировать и скачать в формате Markdown.

## Как устроен проект

```text
meeting-to-spec/
|- backend/                  FastAPI и интеграции с AI
|  |- main.py                HTTP API, проверка файлов, обработка ошибок
|  |- transcription.py       распознавание речи через Groq Whisper
|  |- analysis.py            разбиение транскрипции, вызов и проверка YandexGPT
|  |- prompts.py             системный промпт и шаблон запроса
|  `- tests/                 модульные и API-тесты
|- frontend/                 React, TypeScript и Vite
|  `- src/                   интерфейс, плеер, поиск, редактор и экспорт
`- examples/                 примеры встреч для демонстрации
```

Поток данных:

1. Браузер отправляет файл в `POST /api/analyze` как `multipart/form-data` с полем `file`.
2. Backend сохраняет файл во временную папку и проверяет расширение и размер.
3. Groq Whisper возвращает текст и временные сегменты.
4. Длинная транскрипция делится на фрагменты до 12 000 символов.
5. YandexGPT извлекает структуру ТЗ из каждого фрагмента.
6. Backend проверяет JSON, объединяет и очищает результаты.
7. Frontend показывает результат, связывает требования с фрагментами и формирует `.md` файл.

## Используемые API

- Groq API, модель `whisper-large-v3-turbo` - распознавание русской речи.
- Yandex Cloud Foundation Models API, модель `yandexgpt-lite` - извлечение требований.

Ключи хранятся только в `backend/.env`. Промпты вынесены в [backend/prompts.py](backend/prompts.py), чтобы их можно было проверять и менять отдельно от сетевого кода.

## Локальный запуск

Нужны Python 3.11 или новее и Node.js 20 или новее.

Backend, первый терминал PowerShell:

```powershell
Set-Location 'C:\Users\tribal\Documents\hackathon\backend'
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
# Заполните GROQ_API_KEY, YANDEX_API_KEY и YANDEX_FOLDER_ID в .env
.\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Frontend, второй терминал PowerShell:

```powershell
Set-Location 'C:\Users\tribal\Documents\hackathon\frontend'
npm ci
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Документация API доступна на [http://localhost:8000/docs](http://localhost:8000/docs), проверка состояния - `GET /health`.

Если локальный `backend/.env` уже существует, не заменяйте его примером.

## Поддерживаемые файлы и ошибки

Допустимы `.mp3`, `.mp4`, `.wav`, `.m4a` и `.webm` размером до 25 МиБ. Проверка размера выполняется при потоковой записи, поэтому файл не загружается целиком в память. Временные файлы удаляются и после успеха, и после ошибки.

Backend повторяет временные запросы к внешним сервисам. Если провайдер отклоняет содержимое, перегружен или не отвечает, API возвращает безопасное сообщение, заголовок `X-Error-Code` и идентификатор `X-Request-ID`. Очень длинный текст анализируется по частям. Для записи, которой недостаточно восьми частей анализа, API просит разделить исходный файл.

Ограничение 25 МиБ относится к приложению. При публикации такое же или большее ограничение нужно настроить в reverse proxy и на хостинге.

Тесты используют заглушки и не расходуют лимиты Groq или YandexGPT.

## Демонстрационные записи

В папке [examples](examples) находятся две короткие записи и их текстовые сценарии. Их можно сразу загрузить через интерфейс. Голос синтезирован локально, поэтому содержание воспроизводимо и не содержит персональных данных.

## Ограничения MVP

- Распознавание зависит от качества звука и доступности Groq.
- Один медиафайл передается в Groq целиком. Если провайдер отклонит конкретный кодек, запись нужно перекодировать в MP3 или WAV.
- AI может ошибаться, поэтому итоговое ТЗ нужно проверить перед использованием.
- Ручные правки хранятся на странице до обновления браузера. Для сохранения скачайте Markdown.
- Авторизация пользователей, база данных и промышленное развертывание пока не реализованы.
